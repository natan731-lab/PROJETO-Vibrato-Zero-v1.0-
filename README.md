## 📋 Sobre o Projeto

O **Vibrato Zero** é uma solução mobile de alta performance focada em **Sanitização de Dados (Secure Eraser)**. O objetivo principal é garantir que o espaço livre de dispositivos móveis seja higienizado permanentemente, impedindo a recuperação de informações sensíveis por softwares de perícia digital.

Este projeto foi desenvolvido sob os pilares de **Privacy by Design**, garantindo conformidade com a **LGPD (Lei Geral de Proteção de Dados)** e diretrizes globais de Governança de TI.

## 🚀 Funcionalidades de Elite

* **Wiping Engine:** Sobrescrita de bits em três níveis:
    * **Rápido:** Preenchimento com Zeros (0x00).
    * **Aleatório:** Uso de CSPRNG (Cryptographically Secure Pseudo-Random Number Generator).
    * **Militar:** Padrão **DoD 5220.22-M** (3 passagens).
* **Integridade Garantida:** Geração de Hash **SHA-256** ao final de cada operação para auditoria.
* **Identity & Access Management (IAM):** Autenticação biométrica integrada para acesso restrito.
* **Log de Auditoria GRC:** Histórico completo de operações para fins de conformidade e transparência.
* **Interface Vibrato Glass:** Design moderno com foco em usabilidade mobile (Celular/Tablet) e responsividade.

## 🛠️ Tecnologias e Arquitetura

* **Frontend:** React Native / Aceternity UI.
* **Backend & Criptografia:** AES-256 para logs e hashes SHA-256.
* **Banco de Dados:** SQLite (Armazenamento local de logs de auditoria).
* **Metodologias:** Privacy by Design, GRC.
